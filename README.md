# Linux Log Analyzer

A beginner cybersecurity project written in Python.

## Features

- Reads Linux log files
- Detects failed login attempts
- Generates a security report

## Technologies Used

- Python

## How to Run

```bash
python log_analyzer.py
```

Enter the log file path when prompted.
